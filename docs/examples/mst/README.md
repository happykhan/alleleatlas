Example MST plots for ST313 sample

These example images were generated with `approx.mst_and_plot.plot_mst()` using
`spring_iterations=1200` and `curved_edges=True` to reduce edge overlap and
allow the spring layout to converge for larger components.

Files:
- `st313_sklearn_curved_1200.png`
- `st313_hnsw_curved_1200.png`
- `st313_minhash_curved_1200.png`

They are located in this directory for easy review.
